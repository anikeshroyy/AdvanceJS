# 🎬 Movie Explorer

A dynamic JavaScript-based Movie Explorer application that allows users to manage, search, filter, sort, and analyze a collection of movies.

This project is designed to strengthen intermediate JavaScript concepts such as Objects, Arrays of Objects, DOM Manipulation, Array Methods, Functions, and Problem Solving.

---

# 📚 Learning Goal

This project focuses on mastering:

- Objects
- Arrays of Objects
- Functions
- DOM Manipulation
- Event Handling
- Template Literals
- `forEach()`
- `find()`
- `filter()`
- `some()`
- `every()`
- `sort()`
- `localeCompare()`
- Object Manipulation
- Dynamic UI Rendering

# 🧱 Movie Object Structure

```javascript
{
    id: 1,
    title: "Interstellar",
    genre: "Sci-Fi",
    language: "English",
    releaseYear: 2014,
    duration: 169,
    rating: 9.2
}
```
